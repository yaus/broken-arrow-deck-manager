Broken Arrow Deck Manager - Codex Restore Notes

Project purpose:
- Windows PySide6 desktop tool for Broken Arrow deck backup, switching, notes, branch/version checks, and folder management.
- Project metadata is defined in pyproject.toml and targets Python 3.14+.

Important folders:
- src/ : main source
- assets/icons/ : icons used by source and packaged build
- locales/ : runtime-loaded UI language files
- packaging/BrokenArrowDeckManager.spec : PyInstaller spec
- deck_sets/ : source-run saved deck data

Run from source:
- python .\src\broken_arrow_deck_manager.py

Install locally:
- python -m pip install -e .
- python -m pip install -e .[dev]
- python -m pip install -e .[build]

Build packaged app:
- python -m PyInstaller --noconfirm --clean .\packaging\BrokenArrowDeckManager.spec

Current behavior:
- Source runs use project root as APP_ROOT.
- Packaged runs use the exe folder as APP_ROOT.
- UI languages are loaded from locales/*.json.
- Settings file is deck_manager_settings.json beside APP_ROOT.
- Default saved deck folder is APP_ROOT\deck_sets.
- Default active game deck folder is %USERPROFILE%\AppData\LocalLow\SteelBalalaikaStudio\BrokenArrow\Decks.
- UI currently ships with 10 locales: en, zh-Hant, zh-Hans, ja, ko, ru, de, fr, es, pt-BR.
- File -> Options lets the user change saved deck folder, active deck folder, and language.

Packaging notes:
- Spec bundles deck_sets, locales, and the .ico file.
- Packaged exe output is dist\BrokenArrowDeckManager\BrokenArrowDeckManager.exe.
